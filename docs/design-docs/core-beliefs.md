# Core Beliefs

## Humans Steer, Agents Execute

Humans set goals, constraints, and acceptance criteria. Agents inspect the repository, make scoped changes, run gates, and leave durable context.

## Source Is Not Enough

The source tree explains what exists. Docs explain why it exists, how to change it, and where risks live.

## Side Effects Must Be Visible

Search, browser automation, code execution, and provider calls all have external effects. Code should make those boundaries easy to find and test.

## Degrade Gracefully

Optional providers should improve capability without making basic workflows unusable.
