# Product Sense

## Purpose

Agentic Internet helps users run autonomous internet tasks through a Python package and CLI: search, browser interaction, research synthesis, code execution, and multi-model orchestration.

## Core Beliefs

- Agents are most useful when their tools are explicit and inspectable.
- Research workflows should degrade gracefully when premium providers or API keys are missing.
- Browser automation should be treated as a powerful side effect and surfaced clearly to users.
- CLI workflows should be scriptable, debuggable, and friendly for interactive use.
- Multi-model orchestration should improve task fit without making execution opaque.

## Non-Goals

- This project is not a hosted SaaS by default.
- This project should not hide provider costs or external API usage from users.
- This project should not execute arbitrary code without clear boundaries and tests.
- This project should not require every optional provider key for basic usage.

## Primary Users

- Developers building internet-capable agents.
- Researchers automating multi-step web investigation.
- Agent engineers testing provider, browser, and MCP integrations.
